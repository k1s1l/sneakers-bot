# Каталог кросівок — Telegram-бот

## Як запустити

1. Встанови залежності:
   ```
   pip install -r requirements.txt
   ```

2. Отримай токен бота у [@BotFather](https://t.me/BotFather).

3. Дізнайся свій chat_id, наприклад через [@userinfobot](https://t.me/userinfobot) —
   саме на нього бот надсилатиме заявки та питання клієнтів.

4. Задай токен, chat_id і ключ Claude API:
   - через змінні оточення:
     ```
     export BOT_TOKEN=твій_токен_бота
     export OWNER_CHAT_ID=твій_chat_id
     export ANTHROPIC_API_KEY=твій_ключ_claude_api
     ```
   - `BOT_TOKEN` і `OWNER_CHAT_ID` також можна задати прямо на початку `bot.py`.
   - `ANTHROPIC_API_KEY` бере офіційний SDK автоматично з оточення — окремо в коді
     передавати не потрібно, головне щоб змінна була встановлена в системі перед запуском.
   - Ключ Claude API можна створити в [Claude Console](https://console.anthropic.com/).

5. Поклади фото товарів у папку `photos/` з такими іменами (щоб бот їх підхопив):
   - `photos/adidas_handball_spezial.jpg`
   - `photos/nike_vomero_5.jpg`
   - `photos/new_balance_530.jpg`
   - `photos/asics_gel_kayano_14.jpg`
   - `photos/salomon_xt6_gtx.jpg`

   Якщо фото ще немає — бот просто надішле текстову картку товару без збою.

6. Запусти бота:
   ```
   python bot.py
   ```

## Що вміє бот

- **🛍 Каталог** — показує 5 моделей кросівок з фото, назвою, ціною і доступними розмірами.
- **📏 Розміри** — клієнт вводить будь-який розмір, бот каже, чи є він (діапазон 36–47).
- **💬 Задати питання** — Claude одразу генерує коротку відповідь клієнту на основі каталогу,
  а питання + відповідь пересилаються власнику для контролю.
- **📝 Замовити** — покроково питає модель → розмір → ім'я → телефон/Telegram, після чого
  надсилає готову заявку власнику в Telegram.
- Клієнт може писати вільним текстом без меню (навіть з помилками чи описово,
  напр. «а є щось схоже на спешл?» або «сорок другий є?») — спершу бот пробує
  просте зіставлення за словником, а якщо не вдалось — запит іде в Claude API,
  яка визначає, що саме мав на увазі клієнт: модель, розмір чи довільне питання.
- Якщо розміру немає в діапазоні 36–47 → «На жаль, такого розміру зараз немає 😔»
- Якщо моделі немає в каталозі → «На жаль, такої моделі зараз немає в наявності.»

### Claude API у боті

Модель `claude-haiku-4-5-20251001` (файл `ai.py`) використовується для:
1. розпізнавання наміру клієнта у довільному тексті (модель / розмір / питання);
2. генерації короткої відповіді на вільні питання клієнта.

Якщо `ANTHROPIC_API_KEY` не заданий або стався збій запиту до API — бот не падає,
а просто повертає безпечний fallback (`intent: "unclear"`) і просить скористатись меню.

## Ціни/асортимент

Ціни, розміри та модельний ряд задані у словнику `PRODUCTS` на початку `bot.py` —
онови їх під свій реальний асортимент.

## Деплой на Railway

1. Створи репозиторій на GitHub і завантаж туди всі файли з цієї папки
   (`bot.py`, `ai.py`, `requirements.txt`, `Procfile`, `photos/` з реальними фото).
   Файл `.gitignore` вже виключає кеш і `.env`, щоб секрети туди не потрапили.

2. На [railway.app](https://railway.app) → **New Project → Deploy from GitHub repo**
   → обери свій репозиторій.

3. У розділі **Variables** проєкту додай три змінні (значення — без лапок):
   - `BOT_TOKEN`
   - `OWNER_CHAT_ID`
   - `ANTHROPIC_API_KEY`

4. Railway сам визначить Python-проєкт і встановить залежності з `requirements.txt`.
   Завдяки `Procfile` (`worker: python bot.py`) він запустить бота як фоновий процес
   (без веб-порту, це нормально — Telegram-бот не є веб-сервером).

5. Після деплою перевір логи в Railway — має з'явитись успішний старт polling,
   без помилок. Бот одразу почне відповідати в Telegram.

**Важливо:** файл `bot.py` бере `BOT_TOKEN`/`OWNER_CHAT_ID` зі змінних оточення
(`os.getenv(...)`), а `ANTHROPIC_API_KEY` офіційний SDK Anthropic теж читає
з оточення автоматично — тому нічого редагувати в коді не треба, все налаштовується
через Variables у Railway.
